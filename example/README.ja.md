## 依存関係の解決

```sh
pnpm install --frozen-lockfile
```

```sh
pnpm dev
```

### タイプチェック

```sh
pnpm type-check
```

### [ESLint](https://eslint.org/)でコードチェック

```sh
pnpm lint
```

### [Prettier](https://prettier.io)でコード整形

```sh
pnpm format
```
